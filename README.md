# Hess Truck Repair website

Production website for **Hess Truck Repair LLC**, a heavy-duty diesel repair shop serving Lancaster County, Pennsylvania and surrounding areas.

Live site: [hess-truck-repair.galasriniel18.chatgpt.site](https://hess-truck-repair.galasriniel18.chatgpt.site/)

## Project structure

- `dist/index.html` — page content and structure
- `dist/styles.css` — global styles, navigation, and hero
- `dist/sections.css` — services, shop, reviews, service area, contact, and responsive layouts
- `dist/pamphlet.css` — owner story and pamphlet-derived components
- `dist/app.js` — navigation and quote-request interactions
- `dist/assets/` — optimized production images
- `server.cjs` — lightweight local preview server

## Run locally

The site has no build step and requires only Node.js:

```bash
node server.cjs
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173).
